Relay sits between your MCP client and the servers, projects and knowledge it works with. Every call is checked against your access.

  1. Step 1 of 4

    Authenticate the call.

    Codex sends a request with your MCP Access Token. Relay checks the token, project and server scope before recording the request.

    tools/call fetch_logs
    Authorization: Bearer ****
  2. Step 2 of 4

    Retrieve Knowledge.

    Relay searches product documents and confirmed Memory for relevant context. Only authorized scopes are queried.

    Cache clear sequence for 21.3

    Stop services, clear FormsBin, restart in order. Verified in development.

    Confirmed Memory
  3. Step 3 of 4

    Run it on the right server.

    Relay reaches the analysis server over SSH or hands the job to a Relay Agent. Results and logs are captured as Evidence.

    [SSH] tail -n 100 /var/log/app.log
    → Evidence #ae7f3c
  4. Step 4 of 4

    Review and confirm Memory.

    The agent submits what it learned with memory_capture. An administrator reviews the outcome and conditions, then confirms it as Project or General Memory.

    Status: Pending review

    Submitted. Not searchable until confirmed.

First three steps to your first call

  1. Request access

    Submit a username and password. You can sign in once an administrator approves it.

  2. Choose the token scope

    Create an MCP Access Token for selected projects and servers, or for product Knowledge and General Memory only.

  3. Connect your client

    Add the endpoint and token to Codex or another MCP client. The token secret is shown once.

{
"mcpServers": {
"relay": {
"url": "https://relay.example.com/mcp",
"headers": {
"Authorization": "Bearer YOUR_TOKEN"
}
}
}
}

Questions

Which credentials does Relay manage?

MCP Access Tokens connect clients such as Codex to Relay. Relay Agent Tokens connect configured Windows agents. Neither is a model provider API key.

Do I need a project to use Knowledge?

No. Product Knowledge and General Memory follow a permission on your account. Project Memory requires access to its project.

When does an experience become Memory?

An agent submits a candidate with memory_capture. It becomes searchable only after an administrator confirms it.

Does Relay need an inbound port on Windows servers?

No. The Relay Agent runs as a Windows service and only makes outbound requests to Relay.
